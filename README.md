# DepthMSA project page

Static project page for "DepthMSA: Combinatorial Training and Budget-Aware Depth Allocation for Multimodal Sentiment Analysis". No build step: `index.html` plus the figures in `static/images/`.

Preview locally with `python3 -m http.server` and open http://localhost:8000.

When the arXiv link and the code are public, replace the two `btn soon` placeholders near the top of `index.html` with links.
