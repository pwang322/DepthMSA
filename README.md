# DepthMSA project page

Static project page (this `gh-pages` branch) for "DepthMSA: Combinatorial Training and Budget-Aware Depth Allocation for Multimodal Sentiment Analysis". No build step: `index.html` plus the figures in `static/images/`.

Preview locally with `python3 -m http.server` and open http://localhost:8000.

When the arXiv link is public, replace the `btn soon` placeholder near the top of `index.html` with a link.
